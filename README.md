Monitoring Tilt and Balance Using MPU6050, NodeMCU ESP8266 and KiwisIoT
About the Project
The Monitoring Tilt and Balance is an IoT-based project designed to detect and monitor the tilt angle, orientation, and balance of an object in real time.

Using a NodeMCU ESP8266 microcontroller and an MPU6050 sensor, the system measures acceleration and angular movement to detect changes in the object's position and inclination. The collected sensor data is transmitted to the KiwisIoT platform through Wi-Fi, allowing users to monitor tilt and balance readings remotely through an online dashboard.

By integrating KiwisIoT, this project demonstrates a simple and effective approach to motion detection, orientation monitoring, real-time data visualization, and IoT-based connectivity.
